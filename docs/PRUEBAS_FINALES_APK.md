Pruebas de seguridad

Cobrador no debe gestionar usuarios.
Cobrador no debe entrar a auditoría.
Cobrador no debe entrar a respaldo.
Cobrador no debe editar configuración del negocio.
Administrador sí debe poder ver todo.
